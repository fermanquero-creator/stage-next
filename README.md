# Discovery Hub

Crea una aplicación web para apoyar a artistas emergentes y ayudar a los usuarios a descubrir nuevos talentos.

Usuarios

Artistas: crean y administran su perfil.

Público: explora y descubre artistas.

Funciones principales

Registro e inicio de sesión.

Crear perfil de artista con foto, nombre artístico, biografía y género musical.

Agregar canciones, discografía, portafolio y próximos eventos.

Subir archivos de canciones.

Buscador de artistas.

Filtros por género musical.

Tarjetas de artistas con información básica.

Página de perfil completa con canciones, eventos y contacto.

Diseño

Interfaz moderna, sencilla y visual, enfocada en música y artistas. La navegación debe ser fácil y funcionar bien en computadora y celular.

Objetivo

Crear un espacio donde artistas que están comenzando puedan mostrar su trabajo y donde los usuarios puedan descubrirlos fácilmente.
